# Nimtech Terrace Calculator

Прототип для calc.nimtech.ru.

Файлы: `index.html`, `style.css`, `app.js`, `config.js`.

Уже заложены основания (грунт/бетон/кровля), доски 3/4/6 м, лаги 40×40×2, пояс 80×80×2, сваи 2500 мм (2000 мм под крыльцо), шаг свай 1000–2000 мм, минимальный отступ 400 мм, сдвоенные лаги под стыками и свес доски 100–150 мм.

Точные инженерные алгоритмы продолжаем добавлять по утверждаемому ТЗ.
